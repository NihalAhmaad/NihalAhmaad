## 📌 Featured Projects

### 🔬 Colony-Forming Assay Analysis
Automated pipeline for counting colonies in high-resolution lab plate images: detects and isolates plates, segments colonies (CLAHE, adaptive thresholding, Otsu), filters scratches and container marks with size thresholds, and reports colony counts per image.
`Python` `OpenCV` `scikit-image` `Pandas`

### 🏥 [MediBOT](https://github.com/NihalAhmaad/MediBOT)
RAG-based medical chatbot that answers symptom-related queries using a fine-tuned Llama-2 model and a Pinecone vector database, with a Flask web interface.
`Python` `Llama-2` `LangChain` `Pinecone` `Flask`

### 👄 [Lip-Reading Recognition](https://github.com/NihalAhmaad/Lip-Reading-Recognition)
ML model that recognises spoken words from lip movements in video, with a Streamlit demo.
`Python` `PyTorch` `scikit-learn` `Streamlit`

### 📝 Exam Question Generator (university project)
RAG application that generates exam questions from uploaded German course PDFs: chunking and embedding with Arcana, retrieval of relevant passages, question generation with Llama 3.1, Flask front end. Code is not public.
`Python` `Llama 3.1` `Flask` `Docker`
